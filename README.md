# Sorting Illustrator

A web-based sorting algorithm visualizer built using HTML, CSS, JavaScript, and Bootstrap. The project helps users understand how popular sorting algorithms work through animated bar visualizations.

Have a look at the live version here: https://mahathi17v.github.io/Sorting-Illustrator/

<details>
<summary><strong>Implemented Algorithms</strong></summary>

- Selection Sort
- Bubble Sort
- Insertion Sort
- Quick Sort
- Merge Sort

</details>

<details>
<summary><strong>Features</strong></summary>

- Random Array Generation
- Custom Array Input Support
- Adjustable Array Size
- Adjustable Sorting Speed
- Interactive Sorting Visualizations

### Interpretation of Colors

- 🟢 Green — Default / Unsorted Elements
- 🟠 Orange — Sorted Elements
- 🟡 Yellow — Current Position (Selection Sort, Bubble Sort, Insertion Sort)
- 🔴 Red — Local Minimum (Selection Sort) & Pivot Element (Quick Sort)
- 🔵 Blue — Elements being partitioned (Quick Sort)

</details>

<details>
<summary><strong>Technologies Used</strong></summary>

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5

</details>

<details>
<summary><strong>How to Use</strong></summary>

1. Generate a random array or enter a custom array.
2. Adjust the array size and animation speed.
3. Select a sorting algorithm.
4. Observe the sorting process step-by-step.

</details>

<details>
<summary><strong>Custom Array Example</strong></summary>

Input:

50,20,90,10,40

Click **Load Custom Array** to visualize and sort your own data.

</details>
